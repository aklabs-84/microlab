# 마이크로비트에 프로그램 올리기 (딱 한 번만)

이 프로그램은 마이크로비트가 **센서값을 컴퓨터로 보내고**, 컴퓨터가 시키면 **LED에 그림을 보여 주게** 해 줍니다.
한 번 올려 두면 이후에는 웹 앱만 쓰면 됩니다. (v1, v2 모두 사용 가능)

## 선생님이 한 번만 하면 되는 일 (.hex 만들기)

1. 크롬에서 <https://makecode.microbit.org> 를 엽니다.
2. **새로운 프로젝트**를 만듭니다. (이름 예: 마이크로랩)
3. 화면 위쪽의 **블록 / JavaScript** 중 **JavaScript**를 누릅니다.
4. 안에 있는 내용을 모두 지우고, 이 폴더의 `microlab-firmware.ts` 내용을 **전부 복사해서 붙여 넣습니다.**
5. 왼쪽 시뮬레이터에 오류가 없는지 확인합니다. (확장 기능은 추가하지 않습니다)
6. 아래의 **다운로드** 버튼으로 `.hex` 파일을 받습니다.

## 학생(또는 선생님)이 마이크로비트마다 하는 일

1. 마이크로비트를 USB 케이블로 컴퓨터에 꽂습니다. (충전 전용 케이블은 안 돼요. 데이터 케이블이어야 합니다.)
2. 컴퓨터에 **MICROBIT**라는 이름의 USB 드라이브가 나타납니다.
3. 받아 둔 `.hex` 파일을 그 드라이브로 **끌어다 놓습니다.**
4. 마이크로비트 뒷면의 노란 불이 깜박이다 멈추면 끝입니다. 화면에 하트가 잠깐 보였다 사라집니다.

## 안 될 때

- 앱에서 연결은 되는데 그래프가 안 움직여요 → 위 1~4번을 했는지 확인하세요.
- 연결 창에 장치가 안 보여요 → 케이블이 데이터용인지, 다른 USB 포트로 바꿔도 같은지 확인하세요.
- "다른 곳에서 쓰고 있어요"라고 나와요 → MakeCode 탭 등 마이크로비트를 쓰는 다른 탭을 닫고 다시 시도하세요.

## 블루투스로 선 없이 쓰기 (micro:bit v2 전용)

- 파일: `microlab-ble-firmware.ts`(소스), `microlab-ble.hex`(바로 올릴 파일)
- 올리는 방법은 위와 같습니다. 건전지 팩을 연결하면 USB 케이블 없이 쓸 수 있어요.
- 직접 `.hex`를 만들 때: MakeCode에서 **확장 프로그램 → bluetooth**를 추가하고(radio는 자동으로 제거됩니다),
  **프로젝트 설정 → "페어링이 필요하지 않습니다"**를 켠 뒤 `microlab-ble-firmware.ts`를 붙여 넣습니다.
- 앱에서는 "📶 블루투스로 연결 (v2)" 버튼을 누르고 목록에서 "BBC micro:bit"를 고릅니다. 크롬/엣지에서만 됩니다.
- v1은 블루투스 방식을 쓸 수 없습니다. USB 방식(`microlab.hex`)을 쓰세요.

## 마이크로비트 버전 표시

`microlab.hex`는 연결될 때 `hw:1` 또는 `hw:2`를 보내고, 앱이 연결 상태 옆에 "micro:bit v2"처럼 보여 줍니다.
(이 기능이 없는 예전 `.hex`를 쓰면 버전은 표시되지 않습니다.)
